# 制約・対象外一覧

## 1. 概要

### 1.1 目的

本ドキュメントは、MVP開発における制約条件および対象外範囲を定義する。
スコープ肥大化を防ぎ、価値仮説検証に集中することを目的とする。

## 2. 基本方針

### 2.1 方針

- MVPは「意味で選べるか」の検証に特化する
- 完成度ではなく検証速度を優先する
- 不要な最適化は行わない

## 3. 対象外機能

### 3.1 機能系

| 分類     | 内容               | 理由                 |
| -------- | ------------------ | -------------------- |
| 決済     | 商品購入機能       | レコメンド検証に不要 |
| 配送     | 配送管理           | EC機能は対象外       |
| 会員管理 | 認証・ユーザー管理 | MVPでは不要          |
| 決済連携 | 外部EC連携         | スコープ外           |
| 履歴管理 | レコメンド履歴     | 優先度低             |
| 通知     | メール・Push通知   | 検証に不要           |

### 3.2 UI / UX

| 分類                 | 内容               | 理由             |
| -------------------- | ------------------ | ---------------- |
| デザイン最適化       | UIの洗練           | 検証に不要       |
| パーソナライズUI     | ユーザー別UI最適化 | スコープ外       |
| 高度インタラクション | アニメーション等   | 本質価値ではない |

### 3.3 レコメンド精度

| 分類         | 内容           | 理由         |
| ------------ | -------------- | ------------ |
| 高精度モデル | 精度最大化     | MVPでは不要  |
| 重み最適化   | パラメータ調整 | 後工程       |
| 高度特徴量   | Feature拡張    | 8次元で固定  |
| 画像解析     | CV処理         | 初期は対象外 |

### 3.4 分析・評価

| 分類             | 内容               | 理由             |
| ---------------- | ------------------ | ---------------- |
| 高度分析         | BI・ダッシュボード | MVP外            |
| リアルタイム分析 | ストリーム処理     | 不要             |
| 自動最適化       | AutoML等           | 検証段階では不要 |

## 4. 技術制約

### 4.1 アーキテクチャ

| 項目         | 制約内容                                                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| サービス構成 | 単一リポジトリを前提とし、論理的な分割（web/api/reco/batch）は許容するが、独立したマイクロサービスとしての分離・運用は行わない |
| スケーリング | 個別サービス単位でのスケーリングは考慮せず、全体としての単一デプロイ前提とする                                                 |
| 可用性       | 高可用性構成は取らない                                                                                                         |

### 4.2 データ

| 項目         | 制約内容           |
| ------------ | ------------------ |
| データソース | 外部API依存        |
| データ品質   | 不完全データを許容 |
| データ更新   | バッチ更新のみ     |

### 4.3 モデル

| 項目       | 制約内容           |
| ---------- | ------------------ |
| Feature数  | 8次元固定          |
| モデル更新 | 手動更新           |
| 学習       | オンライン学習なし |

## 5. 運用制約

### 5.1 運用範囲

| 項目       | 制約内容   |
| ---------- | ---------- |
| ユーザー数 | 小規模想定 |
| サポート   | 手動対応   |
| 監視       | 最小限     |

### 5.2 ログ・監視

| 項目     | 制約内容       |
| -------- | -------------- |
| ログ粒度 | 必要最低限     |
| アラート | 基本なし       |
| 分析     | オフライン中心 |

## 6. スコープ境界ルール

### 6.1 判断基準

以下に該当する場合は対象外とする：

- 価値仮説検証に直接関係しない
- 精度向上のみを目的とする
- UX改善のみを目的とする
- 将来拡張のための設計

### 6.2 例外条件

以下の場合のみ実装を許可：

- KPIに直接影響する
- ユーザーが理解できないリスクがある
- 検証結果が歪む可能性がある

## 7. リスク

| リスク     | 内容                 |
| ---------- | -------------------- |
| 精度不足   | レコメンド品質が低い |
| UX不足     | 理解されない         |
| データ不足 | 意味推定が弱い       |
