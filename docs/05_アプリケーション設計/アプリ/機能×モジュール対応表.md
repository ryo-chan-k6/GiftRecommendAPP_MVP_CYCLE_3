# 機能×モジュール対応表

## 1. 概要

### 1.1 目的

本ドキュメントは、Gift Recommendation Service MVPにおける機能とモジュールの対応関係を定義する。

`機能一覧.md` では、ユーザー価値・業務処理・システム責務の観点から必要な機能を整理した。  
`モジュール一覧.md` では、それらの機能を実装責務単位へ分解した。

本ドキュメントでは、以下を明確にする。

```text
どの機能を、どのモジュールが実現するか
どのモジュールが主担当か
どのモジュールが関連・補助するか
Online / Batch / 共通 / 運用の責務が混在していないか
API一覧・バッチ一覧・インターフェース一覧へどう接続するか
```

---

### 1.2 本ドキュメントの位置づけ

| 成果物 | 本ドキュメントとの関係 |
|---|---|
| 機能一覧 | 機能名・機能分類・処理種別・MVP対象の正本 |
| モジュール一覧 | モジュール名・モジュール分類・主責務の正本 |
| 処理構成定義書 | 処理順序、Online / Batch分離、保存タイミングの前提 |
| API一覧 | API化対象機能とAPI担当モジュールを整理する後続成果物 |
| バッチ一覧 | Batch化対象機能とBatch担当モジュールを整理する後続成果物 |
| インターフェース一覧 | モジュール間・外部サービス間の接続を整理する後続成果物 |
| 基本設計・詳細設計 | 各モジュールの詳細処理・入出力・例外処理を定義する後続成果物 |

---

## 2. 対応付け方針

### 2.1 基本方針

| 方針 | 内容 |
|---|---|
| 機能名は機能一覧に合わせる | 本ドキュメントの `機能名` は `機能一覧.md` に定義された名称を使用する |
| モジュール名はモジュール一覧に合わせる | `主モジュール` / `関連モジュール` は `モジュール一覧.md` に定義された名称のみを使用する |
| 主担当を明確にする | 当該機能の実現に最も責任を持つモジュールを `主モジュール` とする |
| 関連モジュールを補助的に記載する | 画面、API、DB保存、ログ、設定参照、外部サービス連携などを `関連モジュール` に記載する |
| Online / Batchを分離する | Online機能にBatchモジュールを直接混在させない。ただし事前生成データの参照は許容する |
| 処理順を反映する | Pre Hard Filter → 候補商品抽出 → Post Hard Filter → Matching → Ranking の順序を反映する |
| 未定義モジュールを混入しない | 新しい責務が必要な場合は、先に `モジュール一覧.md` を更新する |

---

### 2.2 対応区分

| 区分 | 意味 |
|---|---|
| 主モジュール | 機能実現の中心となるモジュール |
| 関連モジュール | 当該機能を補助するモジュール、または前後工程で関係するモジュール |
| 備考 | 処理順、保存対象、後続成果物への注意点など |
