# Web アプリケーション設計成果物

## 1. 目的

本ディレクトリは、`05_アプリケーション設計` 工程における Web（画面・UI）関連成果物の正本配置先である。

画面一覧・画面遷移に加え、Phase4a `web-foundation` で整備するデザインルール・UIコンポーネント一覧を本ディレクトリで管理する。

---

## 2. 成果物一覧

| ファイル名              | 種別               | 概要                                           | MVP対象 |
| ----------------------- | ------------------ | ---------------------------------------------- | ------: |
| 画面一覧.md             | 画面一覧           | 画面 ID・目的・表示項目・MVP 対象の定義        |       ○ |
| 画面遷移図.md           | 画面遷移図         | 画面間遷移・主導線の整理                         |       ○ |
| デザインルール.md       | デザインルール     | 色、余白、タイポグラフィ、部品スタイルの統一   |       ○ |
| UIコンポーネント一覧.md | UIコンポーネント一覧 | 再利用 UI 部品の責務、表示条件、画面対応     |       ○ |

---

## 3. 正本関係

| 対象                      | 正本                                                                 |
| ------------------------- | -------------------------------------------------------------------- |
| 本ディレクトリの成果物    | **本ディレクトリ**（`docs/05_アプリケーション設計/アプリ/web/`）   |
| 技術スタック（web）       | `docs/05_アプリケーション設計/基盤/利用技術スタック整理表.md`    |
| 機能・モジュール対応      | `docs/05_アプリケーション設計/アプリ/機能一覧.md` 等               |
| 画面仕様書（識別子単位）  | `docs/06_実装設計/web/`（Phase4b 以降）                            |
| 共通 UI 実装              | `apps/web/src/components/**`（web-foundation W2 以降）               |
| スタイル基盤              | `apps/web/src/styles/**`（web-foundation W3 以降）                   |

---

## 4. web-foundation との対応

| workstream Task               | 主な成果物                        | 本ディレクトリとの関係               |
| ----------------------------- | --------------------------------- | ------------------------------------ |
| design-system-rules（W1）     | デザインルール・UIコンポーネント一覧 | 正本 docs を作成・更新              |
| common-ui-components（W2）    | `apps/web/src/components/**`      | UIコンポーネント一覧に基づき実装     |
| styles-foundation（W3）       | `apps/web/src/styles/**`          | デザインルールのトークンを実装へ反映 |
| component-test-scaffold（W4） | `apps/web/tests/component/**`     | UIコンポーネント一覧をテスト対象とする |
