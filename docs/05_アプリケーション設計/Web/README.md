# Web 実装設計成果物（web-foundation）

## 1. 目的

本ディレクトリは、Phase4a 横断 Epic `web-foundation` における Web 共通基盤の実装設計成果物を配置する。

W1（デザインルール整備）では、後続 Task（共通 UI 骨格・styles・component test）および Phase4b 画面実装の前提となるデザインルールと UI コンポーネント一覧を定義する。

### 3.1 配置パスについて（Human Review 観点）

`成果物一覧` および `プロジェクトディレクトリ構成定義書` では、同種成果物の工程分類として `06_実装設計/web/` を示している。

一方、Phase4a `web-foundation` の Task Definition / Epic `allowed_paths` では、本 Task の配置先を `docs/05_アプリケーション設計/Web/**` としている。

本 Task（W1）は **Task Definition および Epic `allowed_paths` に従い、本ディレクトリを正本** として整備する。工程分類表との整合は Human Review で確認する。
