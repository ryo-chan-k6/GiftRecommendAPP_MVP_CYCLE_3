## 2. 目的と正本関係

本ドキュメントは、実装フェーズ実行プロセス設計書 §6.4 の「環境変数定義書」に相当する **環境変数一覧の正本** である。

| 情報 | 正本 | 本ドキュメントの役割 |
| --- | --- | --- |
| 環境変数一覧（変数名・用途・秘匿性・設定先） | **本ドキュメント** | 定義 |
| 環境分離・MVP 方針 | [環境設計書](./環境設計書.md) §4〜§8 | 参照 |
| Secret 管理ルール | [認証・認可方針書](../../05_アプリケーション設計/基盤/認証・認可方針書.md) §10 | 参照（ルール本文は重複しない） |

| CI 成功条件 | [CI・CD方針書](../../05_アプリケーション設計/共通/CI・CD方針書.md) | env 名検証観点 |

**本ドキュメントに secret 実値・token・key の実体を記載しない。** 変数名・用途・秘匿性区分・設定先（Secrets / Variables の **名前**）のみを定義する。

## 3. 秘匿性区分

| 区分 | 意味 | Git 管理 | client 公開 | 例 |
| --- | --- | --- | --- | --- |
| `secret` | 認証・接続に使う機密情報 | 不可 | 不可 | `DATABASE_URL`, `OPENAI_API_KEY` |
| `config` | 環境ごとに変わる非機密設定 | 例示のみ | 原則不可 | `RECO_BASE_URL`, `LOG_LEVEL` |
| `public-config` | ブラウザ公開してよい設定（Next.js 等） | 例示のみ | 可 | `NEXT_PUBLIC_API_BASE_URL` |
| `ci-secret` | CI / Batch 実行時のみ利用する secret（運用上の区分） | 不可 | 不可 | GitHub Actions Secrets 経由の同一物理名 |

Secret 管理の詳細は認証・認可方針書 §10.2 を正とする。

## 4. 環境識別子

| 環境 | `APP_ENV` 値 | 備考 |
| --- | --- | --- |
| 開発 | `dev` | ローカル / dev ホスティング |

### 9.1 命名整合（Object Storage / 楽天）

物理名正本は認証・認可方針書 §10.1 および本表とする。

| 正本物理名 | 参照のみ（別 docs の旧表記） | 扱い |
| --- | --- | --- |
| `RAKUTEN_APPLICATION_ID` | `RAKUTEN_APP_ID` | `.env.example` で統一済み |
| `OBJECT_STORAGE_*` | `S3_*`, `STORAGE_*`, `STORAGE_BUCKET_RAW` 等 | 正本は `OBJECT_STORAGE_*` |

**Object Storage 接続方針 A（#1614）:** 製品=Supabase Storage。batch の Raw は S3 互換（`OBJECT_STORAGE_*`）。

外部 API live（楽天・Embedding 等）は **既定 off**。stg での限定 live は明示フラグ／Variables のみ（受入環境方針・E3 方針と整合）。

## 10. GitHub Actions Secrets / Variables 名対応

値は記載しない。リポジトリに登録する **名前** の対応表とする。

| 環境変数名 | GHA 登録種別（推奨） | 備考 |
| --- | --- | --- |
| `DATABASE_URL` | Secret | Batch / 必要なら CI。環境別に別 Secret 名でも可（例: `STG_DATABASE_URL`）※採用時は本表を更新 |
| `OPENAI_API_KEY` | Secret | |
| `RAKUTEN_APPLICATION_ID` | Secret | |
| `RAKUTEN_ACCESS_KEY` | Secret | 採用時 |
| `OBJECT_STORAGE_ACCESS_KEY` | Secret | |
| `OBJECT_STORAGE_SECRET_KEY` | Secret | |
| `OBJECT_STORAGE_BUCKET` | Variable | |
| `OBJECT_STORAGE_ENDPOINT` | Variable | |
| `BATCH_OBJECT_STORAGE_LIVE` | Variable | 既定 `0` / 未設定 |
| `BATCH_INTERNAL_TOKEN` | Secret | 採用時 |
| `SUPABASE_URL` | Variable | 採用時 |
| `SUPABASE_SERVICE_ROLE_KEY` | Secret | 採用時 |
| `RAKUTEN_EXPECTED_EGRESS_IP` | Variable | live 検証時 |
