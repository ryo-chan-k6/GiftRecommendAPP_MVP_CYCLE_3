# 受入テスト

本ディレクトリは、受入テスト工程の成果物を配置する。

## 配置ルール

| パス | 役割 |
| --- | --- |
| `テスト計画/` | テスト方針、対象、範囲、実施条件 |
| `テストケース/` | テストケース、入力データ、期待結果 |
| `テスト結果/` | 実施結果、ログ、エビデンス |
| `レポート/` | テスト結果サマリ、品質評価、残課題 |
