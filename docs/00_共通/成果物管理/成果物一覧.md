# 成果物一覧

## 1. 概要

本ドキュメントは、Gift Recommendation Service MVP Cycle 3 における成果物一覧を定義する。

GitHub Projects 上のタスク管理と、リポジトリ内の成果物ドキュメント管理を対応づけ、設計・実装・テスト・運用改善までの成果物を一元管理することを目的とする。

---

## 2. 更新方針

| 観点       | 方針                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 管理単位   | GitHub Projects上のEpic/Taskを踏まえ、成果物単位で整理する                   |
| 正本       | リポジトリ上のMarkdown/DDL/OpenAPI等の成果物ファイルを正本とする             |
| Projects   | 作業管理・進捗管理・スケジュール管理の正本とする                             |
| Notion     | 必要に応じて閲覧用・整理用の副本として利用する                               |
| 粒度       | 1成果物 = 1ドキュメントまたは1ファイル群を基本とする                         |
| 更新ルール | Projectsに成果物作成タスクを追加した場合、成果物一覧・成果物連関図も更新する |

## 6. 運用ルール

| ------------------ | --------------------------------------------------------------------------------------------------- |

| 成果物削除時       | 削除理由と代替成果物を記録する                                                                      |
| 工程完了時         | 該当Phaseの成果物一覧と成果物連関図をレビューする                                                   |
| 推薦ロジック変更時 | Request / Retrieval / Matching / Ranking / Result / Reason / Feedback / Evaluation の影響を確認する |
