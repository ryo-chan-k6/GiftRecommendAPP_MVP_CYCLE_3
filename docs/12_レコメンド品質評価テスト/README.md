# レコメンド品質評価テスト

本ディレクトリは、レコメンド品質評価テスト工程の成果物を配置する。

## 正本リンク

| 成果物 | パス |
| --- | --- |
| レコメンド品質評価テスト計画書（最小） | [テスト計画/レコメンド品質評価テスト計画書.md](./テスト計画/レコメンド品質評価テスト計画書.md) |

## 配置ルール

| パス | 役割 |
| --- | --- |
| `テスト計画/` | テスト方針、対象、範囲、実施条件 |
| `テストケース/` | テストケース、入力データ、期待結果 |
| `テスト結果/` | 実施結果、ログ、エビデンス |
| `レポート/` | テスト結果サマリ、品質評価、残課題 |
