| generation_type | queue_status | n |
| --------------- | ------------ | -: |
| semantic | skipped | 597 |
| semantic | succeeded | 203 |

`failed` は 0。`skipped` の `error_message` はすべて NULL。

| generation_type | queue_status | n |
| --------------- | ------------ | -: |
| semantic | skipped | 100 |
