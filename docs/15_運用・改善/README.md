# 運用・改善

本ディレクトリは、運用、障害対応、改善活動、モニタリング、フィードバック対応の成果物を配置する。

## 正本リンク

| 成果物 | パス |
| --- | --- |
| 不具合トリアージ運用 | [不具合トリアージ運用.md](./不具合トリアージ運用.md) |

## 配置ルール

| パス | 役割 |
| --- | --- |
| `運用手順/` | 日常運用、確認手順、保守手順 |
| `障害対応/` | 障害対応手順、インシデント記録、再発防止策 |
| `監視・メトリクス/` | 監視項目、メトリクス定義、観測結果 |
| `改善バックログ/` | 運用後の改善候補、追加対応候補 |
| `振り返り/` | リリース後振り返り、改善サイクルの記録 |

正本: [プロジェクトディレクトリ構成定義書](../00_共通/ディレクトリ構成/プロジェクトディレクトリ構成定義書.md)
