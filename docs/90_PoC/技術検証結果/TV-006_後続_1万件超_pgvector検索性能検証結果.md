### 2.2 計測上の注記（事実）

- HNSW 計測では `enable_seqscan=off` で index 経路を強制。

- 1,000 件の HNSW p95 は本体結果（約 2.1〜2.4 ms）と同オーダーで再現。

## 3. 検索時間（p50 / p95 / max）

単位: ms。host=`127.0.0.1:54322`。

| scale | index | top_k | p50 | p95 | max | plan |
| ----- | ----- | ----- | --- | --- | --- | ---- |
| 1,000 | hnsw | 5 | 1.954 | **2.419** | 2.523 | index_scan |
| 1,000 | hnsw | 20 | 1.592 | **2.256** | 3.090 | index_scan |
| 1,000 | seqscan | 5 | 11.010 | 11.961 | 12.282 | seq_scan |
| 1,000 | seqscan | 20 | 9.037 | 12.013 | 12.068 | seq_scan |
| 5,000 | hnsw | 5 | 4.153 | **5.185** | 5.759 | index_scan |
| 5,000 | hnsw | 20 | 2.965 | **3.519** | 3.796 | index_scan |
| 5,000 | seqscan | 5 | 35.638 | 49.045 | 49.266 | seq_scan |
| 5,000 | seqscan | 20 | 35.372 | 45.449 | 47.071 | seq_scan |
| 10,000 | hnsw | 5 | 3.777 | **6.625** | 8.301 | index_scan |
| 10,000 | hnsw | 20 | 3.635 | **5.586** | 8.871 | index_scan |
| 10,000 | seqscan | 5 | 52.617 | 62.940 | 65.715 | seq_scan |
| 10,000 | seqscan | 20 | 50.062 | 69.813 | 78.469 | seq_scan |

### 3.1 HNSW index 構築時間（参考）

| scale | build_ms |
| ----- | -------- |
| 1,000 | 662.5 |
| 5,000 | 6,759.6 |
| 10,000 | 22,471.3 |

**解釈（事実）:** 10,000 件・HNSW 経路の検索 p95 は約 **5.6〜6.6 ms**。同一件数の seqscan p95 は約 **63〜70 ms**。件数増に伴い seqscan が線形に悪化し、HNSW の相対効果が大きい。

**解釈（推論）:** TV-007 の soft/hard（秒オーダー）に対し、類似検索単体は 10,000 件でも十分小さい。カタログが 1 万件規模でも pgvector 単体が支配ボトルネックになる兆候は見当たらない。本番分布・JOIN 込みは別途。

## 4. 判定

| ラベル | 判定 | 根拠 |
| ------ | ---- | ---- |
| **Go** | 暫定採用 | 1万件・HNSW でも検索 p95 < 10 ms。致命懸念なし。本体 TV-006 Go と整合 |
| Adjust | — | 現行 HNSW DDL（`m=16` / `ef_construction=64`）を覆す必要は見当たらない |
| Block | — | なし |

### 4.1 残リスク

| リスク | 扱い |
| ------ | ---- |
| JOIN + Hard Filter 込みの Retrieval | 対象外。必要時は別 Task |
| 本番カタログ分布・欠損 | テストデータでは未再現。必要時は別計測 |
| 1万件超（例: 5万〜） | 未計測。必要になったら別 Task |
| HNSW 構築時間（〜22 s @ 10k） | バッチ構築想定なら許容寄り。オンライン大量再構築は別検討 |
