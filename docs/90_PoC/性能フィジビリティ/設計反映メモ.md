### 2.4 Phase3（Reason 込み）と phase_output 案

詳細は [Phase3 結果 doc](./Reco性能フィジビリティ検証結果_Phase3_reason_e2e.md)。

| 計測系 | Ranking まで（内部 1.5s/2s） | Reason 込み（外部 AI 6s/8s） |
| ------ | ---------------------------- | ---------------------------- |
| live + secrets（GHA） | Block（参考・User Meaning 支配） | **Block**（p95≈12.5s） |
| live + secrets（local） | Block（参考） | **Adjust**（p95≈6.5s） |
| live + mock（GHA/local） | **Go** | **Go** |

| 項目 | 案（推論・Human Review） | 根拠 |
| ---- | ------------------------ | ---- |
| Reason 込み E2E 枠 | **6s/8s と同一**（本 PoC で採用して判定） | #1533 同期外部 AI 込み。Human が別枠にするかは未確定 |
| phase_output soft | **3,000ms** | 旧定義 secrets p50≈2.7–2.8s（合算値）。#1545 後は見直し候補 |
| phase_output hard | **7,000ms** | 旧定義 secrets p95≈3.6–6.4s（local/GHA）。E2E hard 8s 内 |
| 代替案 | soft 2.5s / hard 5s、または hard なし（fallback 継続） | Phase3 §5 |

**計測定義（事実・#1545）:**

| 定義 | 内容 |
| ---- | ---- |
| 旧（Phase3〜#1545 前） | `result_generated` + `reason_generated` + `response_built`（累積壁時計） |
| **新（#1545 以降）** | `result_generated` + `reason_generated`。`response_built` は診断メトリクスとして別集計 |
| Reason 込み E2E | 外側 wall-clock（変更なし） |

旧合算値を「Reason OpenAI 予算」と読まないこと。案 A（3s/7s）は旧定義根拠のため、新定義再計測後の採否・見直しは **Human 判断**（断定しない）。

**Human 判断待ち:** `phase_output` 案 A の採否（新定義向け見直し含む）。Reason 込みを 6s/8s と同一枠にするか。secrets 再計測の要否。
