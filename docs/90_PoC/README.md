# PoC

本ディレクトリは、技術検証、外部API疎通検証、性能フィジビリティ等のPoC成果物を配置する。

PoC成果物は正式成果物ではない。正式設計へ反映する場合は、該当工程の `docs/` 配下へ再整理する。

正本: [プロジェクトディレクトリ構成定義書](../00_共通/ディレクトリ構成/プロジェクトディレクトリ構成定義書.md)  
検証IDの定義正本: [全体テスト計画書](../05_アプリケーション設計/テスト/全体テスト計画書.md) §7.1（TV-001〜TV-010）

---

## 配置ルール

| パス | 役割 |
| --- | --- |
| [`計画/`](./計画/) | 技術検証の全体計画、各TVの要件・実施/検証方針 |
| [`管理/`](./管理/) | TV進捗、棚卸し、依存関係、再開判断の管理資料 |
| `技術検証結果/` | 技術検証の実行結果（レポート本体） |
| `外部API疎通検証/` | 実API疎通検証の結果 |
| `性能フィジビリティ/` | 性能フィジビリティ検証の結果 |
| `検証メモ/` | PoC過程の補足メモ |

### 使い分け

| 置くもの | 置き場 |
| --- | --- |
| 「何を・どの順で・どう検証するか」 | `計画/` |
| 「今どこまで終わっているか」「再開判断」 | `管理/` |
| 「実行して得た数値・ログ要約・判定」 | `技術検証結果/` / `外部API疎通検証/` / `性能フィジビリティ/` |
| 「途中の気づき・暫定メモ」 | `検証メモ/` |
