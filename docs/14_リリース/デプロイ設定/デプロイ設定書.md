## 4. MVP プロバイダ一覧（確定）

| コンポーネント | プロバイダ | 備考 |
| --- | --- | --- |
| Web | **Vercel** | Environment: Preview/dev・stg・Production |
| API | **Render**（等） | Environment で stg / prod 分離 |
| Reco | **Fly.io**（等） | Environment / app で stg / prod 分離 |

「等」とある API / Reco は物理構成図の表記を踏襲。変更する場合は本表と物理構成図を同時更新する。

## 5. 環境別の配置方針

| 環境 | `APP_ENV` | 主な配置 |
| --- | --- | --- |
| local | `dev` | Web/API/Reco はローカル。DB=Supabase CLI。Redis=**Docker compose** |
| 簡易 stg | `stg` | Vercel/Render/Fly の stg。DB=Supabase stg。Redis=**Upstash stg** |
| prod | `prod` | 各 Production。DB=Supabase prod。Redis=**Upstash prod** |

Layer2（GHA ephemeral）の Redis はテスト設計書に従う。本ドキュメントの Upstash 対象は **簡易 stg / prod の常設キャッシュ** とする。

## 6. Upstash Redis 設定方針

### 6.1 作成単位

| 項目 | 方針 |
| --- | --- |
| stg | Upstash 上に **stg 用 Database 1** |
| prod | Upstash 上に **prod 用 Database 1**（stg と共有禁止） |
| local | Upstash を使わない（`docker-compose.dev.yml`） |
| 命名 | データベース名に `stg` / `prod` を含め見誤らない |

### 6.2 接続

| 項目 | 方針 |
| --- | --- |
| 環境変数名 | `REDIS_URL`（[環境変数定義書](../../06_実装設計/cross_cutting/環境変数定義書.md)） |
| プロトコル | TLS を優先（`rediss://` 等。Dashboard の推奨接続文字列に従う） |
| 利用者 | **api と reco の同一環境で同一 URL** |
| 設定先 | API Hosting Secret / Reco Hosting Secret（Environment 単位） |

### 6.3 運用注意

- Redis は必須依存にしない（基盤構成設計書 §5.5）。cache miss でも業務継続可能であること
- 実値を docs / Issue / PR / ログ / local `.env`（stg/prod）に置かない
- 登録・分離確認は [環境変数運用手順](../../15_運用・改善/運用手順/環境変数運用手順.md) に従う
- 構築チェックは [簡易stg構築手順](../../15_運用・改善/運用手順/簡易stg構築手順.md) §6.2

### 6.4 将来

負荷・可用性・ベンダー制約が課題になった場合、Redis Cloud 等への移行を検討する。移行時は本表と H-DEP-* を改訂する。

## 7. アプリ別の設定配置（概要）

詳細な変数名は環境変数定義書を正とする。ここでは **どこに置くか** のみ示す。

| 対象 | 設定の置き場 | 主な変数カテゴリ |
| --- | --- | --- |
| Web（Vercel） | Environment Variables | `NEXT_PUBLIC_*` 等（secret を置かない）。手順・`vercel.json` は [`infra/vercel/README.md`](../../../infra/vercel/README.md) / [`apps/web/vercel.json`](../../../apps/web/vercel.json) |
| API（Render） | Environment / Secret | `DATABASE_URL`, `REDIS_URL`, `RECO_*`, `CORS_*` 等。Build/Start 正本は [`infra/render/README.md`](../../../infra/render/README.md) |
| Reco（Fly） | Secrets / env | `DATABASE_URL`, `REDIS_URL`, `OPENAI_API_KEY`, `RECO_INTERNAL_API_KEY` 等。手順・Dockerfile / `fly.toml` は [`infra/fly/README.md`](../../../infra/fly/README.md) |
| Batch（GHA） | Actions Secrets / Variables | `DATABASE_URL`, Object Storage、楽天、live フラグ等 |
| `infra/*` | README＋設定ファイル | Web=`infra/vercel`+`apps/web/vercel.json`（#1724）。API=`infra/render`（#1718）。Reco=`infra/fly`（#1720） |
