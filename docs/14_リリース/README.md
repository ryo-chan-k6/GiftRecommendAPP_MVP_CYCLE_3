# リリース

本ディレクトリは、リリース手順、リリース判定、リリースノート、初期稼働確認結果を配置する。

## 正本リンク

| 成果物 | パス |
| --- | --- |
| MVPリリース判定チェックリスト | [リリース判定/MVPリリース判定チェックリスト.md](./リリース判定/MVPリリース判定チェックリスト.md) |

## 配置ルール

| パス | 役割 |
| --- | --- |
| `リリース計画/` | リリース対象、スケジュール、前提条件 |
| `リリース手順/` | 本番反映手順、rollback手順、確認手順 |
| `リリース判定/` | リリース可否判断、チェックリスト、承認結果 |
| `リリースノート/` | リリース内容、変更点、既知の制約 |
| `初期稼働確認/` | リリース直後の動作確認結果、監視確認結果 |
