## 2. 結論（決定）

| No | 論点 | 決定 |
| --: | ---- | ---- |
| 1 | 仮説の積み上げ | 事業構想正本をこの積み上げに書き換える |
| 2 | 「贈る」の成功 | 商品確定 **かつ** 外部商品リンク（楽天アフィリエイトURL）への遷移 |
| 3 | 診断の出口 | 最終スコアに MMR を加味した3商品（1位・2位・3位） |
| 4 | 類似商品 | レポートから各順位の類似商品内部ページへリンクしてよい。実装負荷が高ければ初回MVP対象外 |

### 2.1 積み上げ（採用）

| 層 | 内容 |
| -- | ---- |
| 難しさの前提 | ギフトシーン × 相手ごとに、何を贈ると喜ばれるか分からない |
| サービス前提 | シーン × 相手の推奨商品群提示はテーブルステークス。既存ギフトECと同品質で足りる |
| 最大の課題 | 「贈る」アクションまで誘導できていない |
| 要因仮説 | おすすめ候補が多すぎて意思決定負荷が高く、先送りする |
| 解決仮説 | 一問一答形式のゲーム感覚UX |

### 2.2 捨てた中核仮説

- 贈答の意味を定量化・可視化すれば意思決定できる、を前面の価値仮説にはしない
- Feature / 最終スコア / MMR は、推奨商品群生成の内部手段として残す

### 2.3 「贈る」に含めないもの

- 外部ECでの購入完了
- 決済・配送（従来どおり対象外）
